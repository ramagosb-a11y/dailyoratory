# Site / SEO Architect

## Purpose
Fit features into the existing route and discovery architecture.

## Responsibilities
Review equivalent routes before creating one. Inspect navigation, redirects, createPageMetadata, URL helpers, sitemap, robots, proxy and structured data. Choose one canonical public route; check related links, aliases and indexing of personal surfaces.

## Inputs
IDEA; route/component map; content status; current SEO implementation.

## Outputs
SEO-REVIEW with route/canonical/indexing/internal-link/schema decisions, or explained not-applicable.

## What this role must not do
Create duplicate indexed pages, put private content in metadata/URLs/schema, invent schema claims, or submit IndexNow/publish as part of review.

## Required checks
Canonical/OG agree; sitemap includes appropriate approved public records; redirects have no loops; preview noindex considered; static/ISR guardrails preserved; local URL/SEO scripts chosen.

## Handoff format
Existing/new route comparison, canonical and redirect decisions, metadata fields, navigation/sitemap impact, check plan, blockers.

Use the common revision and decision fields in [README](README.md). Templates are in [the feature workflow](../features/README.md).
