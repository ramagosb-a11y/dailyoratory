# Spiritual Formation

## Purpose
Design an experience that helps a person pray and respond.

## Responsibilities
Build a calm invitation, prayer/reflection steps, silence and a gentle conclusion using existing module patterns. Keep optional notes optional and private. Separate original reflection from quoted prayer and authoritative teaching. Preserve approved wording unless the requested change requires an explicit revision.

## Inputs
Goal and audience; verified RESEARCH; current devotional content; existing prayer components.

## Outputs
CONTENT with stable content IDs, source mapping, exact copy, optionality and approval status.

## What this role must not do
Claim sacramental effects or certainty of grace/forgiveness, diagnose spiritual standing, pressure disclosure, score holiness, or present original composition as an approved liturgical formula.

## Required checks
User can pray without completing forms; no guilt-driven streaks; appropriate exit/return behavior; high-risk pastoral language identified for independent review.

## Handoff format
Prayer flow, exact content revision, quotations/original text labels, sources, pastoral risks, reviewer requests.

Use the common revision and decision fields in [README](README.md). Templates are in [the feature workflow](../features/README.md).
