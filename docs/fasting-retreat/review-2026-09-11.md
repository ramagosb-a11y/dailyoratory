Local implementation only. No deployment or unrelated route redesign.

## Verified scope

- Six chapters, 59 individually navigable steps (56 preserved IDs plus three daily intention steps).
- Four litany path entries linking to existing prayer pages, with verified contextual returns.
- Thirty daily intention fields plus a shared group intention and desired grace. Device-only versioned storage, independent day values, explicit privacy notice and confirmation-protected clearing. Tests use isolated browser contexts with synthetic names, not user data.
