# Nightly Examen images

These six devotional photographs were generated for the Daily Oratory Nightly Examen on 2026-09-27 using OpenAI image generation. They are original AI-generated assets with no third-party photographic source or external image request at runtime.

| File | Page | Description |
| --- | --- | --- |
| `presence.webp` | Become Present | A quiet chapel, candle and cross at night |
| `gratitude.webp` | Receive the Day with Gratitude | Evening light in a chapel |
| `review.webp` | Review the Day with God | A person quietly praying in a chapel |
| `mercy.webp` | Recognize Sin and Receive Mercy | A cross and kneeler in warm chapel light |
| `resolution.webp` | Receive God’s Love and Make a Resolution | Dawn beginning in a chapel |
| `surrender.webp` | Rest in God’s Care | A peaceful night sky seen through a church window |

The original generated PNGs were 1536 × 1024 pixels. The deployed WebP versions preserve that 3:2 aspect ratio and were encoded at quality 88 using the repository’s existing `sharp` dependency. Source PNGs remain outside the repository in the local temporary directory; only optimized WebP assets are used by the site.
